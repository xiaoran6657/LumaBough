## 5. README 草稿（要点）

1. **一句话定位**：LumaBough 是一个 Windows 上的小型 RHI/渲染图实验工程，带可复跑的演示与测量工具。
2. **是什么 / 不是什么**：是双后端（D3D11/D3D12）程序化渲染演示与性能实验工具；
   **不是**通用引擎、不是性能承诺、不包含编辑器或资产流水线产品化内容。
3. **支持矩阵**：Windows 10/11 x64；D3D11 与 D3D12；场景 `m4-visual-baseline`；
   app-local VC 运行时 + WinPixEventRuntime；`m7-*` 性能场景与 Capture 工具链不在包内。
4. **快速开始**：按 `RUN.md` 两条命令（D3D12 与 D3D11 各一次），期望 `status PASS` 与 `graphHash`。
5. **验证到什么程度**：候选门（可复跑）+ 第二台机器独立运行（含哈希与逐项结果）+ 隐私处置基线；
   **明确声明：未做真实读者走查**。
6. **声明边界**：不宣称当前加速；历史 C-M9-002 数值是历史结论，与本包无关。
